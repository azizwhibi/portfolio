# Arabsoft RN AI Assistant

## Overview
A mobile AI assistant built with React Native and a Spring Boot backend, featuring secure authentication and a prompt-tuned AI chatbot for instant company knowledge retrieval.

## Tech Stack

- **React Native**: Mobile app framework
- **Spring Boot**: Backend API
- **Java**: Backend language
- **REST API**: API endpoints
- **AI / Chatbot**: Prompt-tuned conversational interface
